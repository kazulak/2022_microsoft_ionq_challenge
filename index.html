How to Play QuanTris

The Core Concept

In Quantum Tetris, the falling blocks are qubits. Instead of filling rows, your goal is to make falling blocks destructively interfere with blocks already on the board to clear them.

Qubits & Arrow Rotations

Qubit states are represented by arrows. The horizontal axis represents the $|0\rangle$ state, and the vertical axis represents $|1\rangle$.

  • Arrow Right: $|0\rangle$ state
  • Arrow Up: $|1\rangle$ state
  • Arrow Diagonal: Superposition state (e.g. $\frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$)

Quantum Gates

Use the gate buttons or keyboard shortcuts to manipulate the active falling qubit's state:

  • X Gate (Key X): Flips the state (NOT operation).
  • Z Gate (Key Z): Phase flip.
  • H Gate (Key H): Puts the qubit in superposition (45° rotation).
  • CX / CZ / CH: Entangle 2-qubit blocks.

💥 Destructive Interference (Clearing Blocks)

When the active block lands on another block of the same shape/squares, they will cancel out and disappear ONLY IF their state vectors are exactly opposite (out of phase by 180°, i.e., $v_{active} = -v_{board}$). This awards you points!
